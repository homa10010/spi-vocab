# SPI言語対策

SPI などの就活適性検査の言語分野（熟語の意味・英単語）を、スマホで解いて覚えるアプリです。

- 熟語：意味の説明を見て、合う言葉を5択から選ぶ（二字熟語・和語・四字熟語・ことわざ）
- 英単語：英単語を見て、日本語の意味を4択から選ぶ
- 「学習を始める」を押すたびに、復習の時期が来た語と新しい語（1回20語、設定で変更可）を出す。回数の制限はない
- 新しい語は100語ずつのステージ順に出し、ステージの語を出し終えると自動で次のステージに進む（正答率8割で「クリア」表示）
- 「ランダム20問」で、ステージに関係なく全語からランダムに解ける
- 覚えた語は、1日後・3日後・7日後・14日後・30日後と間隔を空けて復習に出る
- ホーム画面に追加すると、電波がなくても動く

## 使い方（スマホ）

1. 公開ページ `https://<GitHubのユーザー名>.github.io/spi-vocab/` を開く
2. ホーム画面に追加する
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」
3. 以降はホーム画面のアイコンから開いて学習する
   - iPhone では Safari とホーム画面のアプリで保存場所が別になるため、必ずホーム画面から開く
4. ときどき「設定 → バックアップを書き出す」で進捗を保存しておく

## 公開の準備（初回のみ）

1. GitHub でリポジトリ `spi-vocab` を作成し、このフォルダの内容を `main` ブランチに push する
2. リポジトリの Settings → Pages → Build and deployment → Source を「GitHub Actions」にする
3. `main` に push するたびに、テスト → データチェック → ビルド → 公開 が自動で行われる

## 開発

```bash
npm install
npm run dev          # 開発サーバー（http://localhost:5173/spi-vocab/）
npm test             # 単体テスト
npm run check-data   # 単語データの自動チェック
npm run build        # 本番ビルド（dist/）
```

アイコンを作り直すときは `public/icon.svg` を編集してから、Playwright が入った環境で次を実行する。

```bash
NODE_PATH=$(npm root -g) node scripts/make-icons.mjs
```

## 単語データの追加

データは `src/data/jukugo/stage-NN.json`、`src/data/english/stage-NN.json` に、1ファイル＝1ステージ＝100語で置く。

```jsonc
// 熟語
{ "id": "jk-0101", "type": "二字熟語", "word": "…", "reading": "…", "meaning": "…",
  "level": 1, "confusers": ["jk-0042"], "synonyms": [] }
// 英単語
{ "id": "en-0101", "word": "…", "pos": "動詞", "meaning": "…",
  "level": 1, "confusers": ["en-0120"], "synonyms": [] }
```

- `id` はファイルをまたいで連番（熟語 `jk-0001`〜、英単語 `en-0001`〜）
- `type`：二字熟語・和語・四字熟語・ことわざ／`pos`：名詞・動詞・形容詞・副詞・その他／`level`：1〜3
- `confusers`：字や意味が紛らわしいが、意味は違う語。誤答として優先して出る
- `synonyms`：ほぼ同じ意味の語。誤答に出ないようにする印。必ず双方向に書く
- 問題文・意味はすべてオリジナルで書く（市販の問題集や辞書の文章を写さない）

追加の手順：

1. 300語（3ステージ分）ずつファイルを作る
2. `npm run check-data` がエラー0件になるまで直す
3. 意味の正確さ・紛らわしい語・同義語の漏れを1語ずつ見直す
4. アプリで解いてみて、気になった語を直す
